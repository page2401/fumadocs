本站点由独立仓库 [`page2401/fumadocs`](https://github.com/page2401/fumadocs) 构建，基于主仓库 `page2401.github.io/docs/` 的标准 GFM 原始母版派生适配而来，用于量化 **Fumadocs v16 (`fumadocs-ui@16.19.7` + `fumadocs-core@16.19.7` + `fumadocs-mdx@15.6.4`)** 搭配 **Next.js 16 App Router (`output: 'export'`)** 在 JSX `<Callout>` 组件、Mermaid 12 图表、KaTeX 公式与多级 `meta.json` 目录树编排上的真实工程表现。

## 五大基准测试章节导航

| 章节路径 | 测试维度 | Fumadocs v16 (`16.19.7`) 核心实测特征 |
| :--- | :--- | :--- |
| [`01. 专属标注与元数据`](./01-annotations.mdx) | 专属标注与 MDX 3 组件 | Zod v4 `pageSchema` 强类型校验 Frontmatter；以原生 JSX `<Callout type="info\|warn\|error">` 取代三冒号语法；默认未内置 GFM `> [!NOTE]` 转换 |
| [`02. 流程图与时序图`](./02-diagrams.mdx) | 流程图与时序图 | 官方 `remarkMdxMermaid` 插件在编译期将标准 ```` ```mermaid ```` 转为 `<Mermaid chart="..." />`，由本地 `mermaid@12.3.0` 客户端渲染 SVG |
| [`03. 数学公式排版`](./03-math.mdx) | 数学公式排版 | `remark-math@6.0.0` + 前置 `rehype-katex@7.0.1`（绕过内置 Shiki `rehypeCode` 抢占）+ 本地打包 `katex@0.19.1` 样式与字体 |
| [`04. 目录结构与路由取舍`](./04-directory/index.mdx) | 目录结构与 `meta.json` | `content/docs/` 双层隔离 + 各层级 `meta.json` 声明中文分组名与顺序 + `createRelativeLink` 解析相对 `.mdx` 互链 |
| [`05. 高阶代码块与语法高亮`](./05-code-blocks.mdx) | Shiki 代码块与 `tab="..."` | 内置 `rehypeCode` 支持 `title="..."`、`// [!code highlight]` 与 `// [!code ++]` 词法 Diff；`remarkCodeTab` 原生合并连续 `tab="..."` 代码块 |

## 子模块精确锁定版本档案

| 依赖模块 | 精确锁定版本 | 在本子站中的职责 |
| :--- | :--- | :--- |
| `fumadocs-ui` | `16.19.7` | 基于 Radix UI + Tailwind CSS v4 的文档布局、侧边栏与 `<Callout>` 等 MDX 组件库 |
| `fumadocs-core` | `16.19.7` | 页面树构建器（`loader`）、`meta.json` 解析及 `remarkMdxMermaid` 等编译插件 |
| `fumadocs-mdx` | `15.6.4` | 基于 Zod v4 的内容集合编译器（生成 `.source/server.ts` 类型安全索引） |
| `next` | `16.4.6` | App Router 静态导出宿主框架（`output: 'export'` + `basePath: '/fumadocs'`） |
| `tailwindcss` | `4.3.5` | CSS-first 原子化样式引擎（配合 `fumadocs-ui/css/preset.css`） |
| `remark-math` / `rehype-katex` | `6.0.0` / `7.0.1` | 构建期 LaTeX 公式 AST 解析与 KaTeX HTML 生成 |
| `katex` | `0.19.1` | 本地静态打包数学公式样式表与 Webfont 字体资源（零外部 CDN 请求） |
| `mermaid` | `12.3.0` | 本地打包第 12 代流程图、时序图与状态机客户端 SVG 渲染引擎 |
| `react` / `react-dom` | `19.3.1` | React Server Components 与客户端交互运行时 |
